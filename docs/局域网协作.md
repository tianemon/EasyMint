# 局域网 Git 协作（mac ↔ win）

> 本机开发环境配置（bare 仓库在 mac 本机），非产品功能。用于 mac/win 两台机器间 git 同步。

## 仓库

- **bare 仓库**：mac 本机 `~/easymint-local-sync.git`（纯存档/中转）
- **本机 IP**：`192.168.5.5`（已固定；旧地址 `.9` 已废弃）

## remote 配置

| 端 | remote 地址 |
|----|------------|
| **mac 本机（自用）** | `ssh://amon@localhost/Users/amon/easymint-local-sync.git`（用 localhost 可绕过 VPN 对局域网 IP 的干扰） |
| **其他机器（win 等）** | `ssh://amon@192.168.5.5/Users/amon/easymint-local-sync.git` |

```bash
# 全新拉取
git clone ssh://amon@192.168.5.5/Users/amon/easymint-local-sync.git

# 已有仓库添加远程
git remote add mac ssh://amon@192.168.5.5/Users/amon/easymint-local-sync.git

# 修改远程地址
git remote set-url mac ssh://amon@192.168.5.5/Users/amon/easymint-local-sync.git
```

## SSH 认证

- mac 本机**远程登录已开启**（系统设置 → 通用 → 共享 → 远程登录）
- 各机器**公钥**追加到 mac 本机 `~/.ssh/authorized_keys`（每台一行），实现免密
- 生成 key：`ssh-keygen -t ed25519`

## 日常同步

```bash
# mac 端推送
git push mac main

# win 端拉取
git pull mac main
```

## win 端收尾提醒

win 曾 checkout 临时分支（fix/win-polish，已删），需：

```bash
git checkout main
git pull mac
git remote prune mac
```

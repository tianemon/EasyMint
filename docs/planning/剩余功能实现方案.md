# 剩余功能实现方案

## 一、hooks 校验

**Pi/omp 支持？** 都不支持原版 Claude SDK 的 PreToolUse hook。

**方案**：在 `builtin-mcp.ts` 的 `set_task_status` / `set_project_stage` execute 里内联校验。

```typescript
// 读 task.json → 检查 4 条规则 → 不通过 return error text
function validateTaskStatus(projectPath, taskId, newStatus): string | null {
  const tasks = JSON.parse(readFileSync(join(projectPath, "task.json"), "utf-8")).tasks;
  // ① building 时不能有其他任务在 building/evaluating
  // ② stage=done 时所有任务必须 done 或 failed
  // ③ evaluating 时目标必须 building
  // ④ failed 时目标必须 building 或 evaluating
  return null; // 或错误消息
}
```

不改架构，不加文件。影响范围：仅 `builtin-mcp.ts` 内 2 个 execute 函数。

## 二、MCP 工具桥接

**Pi 支持？** 不支持。**omp 支持？** ✅ MCPManager（纯 JS，Tier 1）。

**方案 A：omp MCPManager 移植**

omp `mcp/manager.ts` 核心 API：
```
MCPManager.instance()
  → discoverAndConnect({ enableProjectConfig: true })
  → connectServers(configs, sources, onStatus)
  → getTools() → CustomTool[]
```

但 omp 读取的是 `.mcp.json` 格式。EM 的 MCP 配置在 `mcp-service.ts` 的 `DEFAULT_MCP_SERVERS` 常量里（`{ playwright: { type: "stdio", command: "npx", args: [...] } }`），格式是 Claude Code 的 `mcpServers`。

**实现路径**：
1. 从 omp 移植 `mcp/manager.ts` + `mcp/client.ts` + `mcp/json-rpc.ts`（纯 JS，替换 `Bun.sleep` 为 `setTimeout`）
2. 写一个适配层把 EM 的 `McpServerConfig` 转成 omp 的 `MCPServerConfig`
3. `buildSession` 中调用 `MCPManager` 获取 MCP 工具，合并到 `customTools`

```
pi-session.ts buildSession():
  const mcpManager = MCPManager.instance();
  await mcpManager.connectServers(emConfigs);
  const mcpTools = mcpManager.getTools();
  const allTools = [...codingTools, ...productTools, ...mcpTools];
```

**方案 B：手写 @modelcontextprotocol/sdk 桥接**

直接用 `@modelcontextprotocol/sdk` 的 `Client` 类连接每个 MCP 服务器 → `listTools()` → 动态生成 `defineTool` wrapper。比方案 A 轻但缺少重连、缓存、OAuth 等。

**建议**：方案 A。omp MCPManager 是久经考验的生产级实现，移植成本约 2 小时。

## 三、自动会话标题

**Pi 支持？** `session.setSessionName(name)` ✅（已实现）。

**方案**：在 `agent-service.ts` 的 `promptAndBridge` 中，首轮 agent_end 后生成标题。

当前 `sendMessage` 里 `firstUserMessage` 字段已记录，但没消费。补上：

```typescript
// promptAndBridge 的 agent_end 处理后
if (chat && chat.firstUserMessage) {
  const firstMsg = chat.firstUserMessage;
  chat.firstUserMessage = "";
  const title = firstMsg.length > 15 ? firstMsg.slice(0, 15) + "…" : firstMsg;
  renameSession(sessionId, title, chat.projectPath);
  broadcast("agent:session-renamed", { sessionId, title });
}
```

## 四、上下文使用率前端显示

**Pi 支持？** `session.getContextUsage()` → `{ tokens, contextWindow, percent }` ✅（已接后端）。

**方案**：前端只需渲染 `agent:context-usage` 事件。当前 `ChatPanel.tsx` 没监听这个事件。在 Effect B 里加处理：

```typescript
if (event.type === "context_usage") {
  useStatusStore.getState().setContextUsage(event.percentage, event.totalTokens, event.maxTokens);
}
```

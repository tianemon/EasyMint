3. **模型名**:状态栏显示当前模型(主进程广播或前端读已有状态)
4. **过渡动词池**(暂缓):无工具调用时从动词池随机抽一个填充(如 Moseying/思索中),每次回合随机——用户暂不考虑,记档

**涉及文件**:`StatusBar.tsx`、`status-store.ts`、`agent-service.ts`(token 累计)、`ChatPanel.tsx`(订阅)

**状态**:待办(用户确认缓做,逐步补齐)

## 3. 会话回退 rewind 功能（未实施）

**背景**:cc 长会话（~1M 上下文）手动 `/compact` 触发 400 后,用户用 `/rewind` 恢复节点继续工作。EM 暂无回退能力。

**调研**:已落盘 `docs/design/会话回退机制调研-cc-rewind与pi-fork对比.md`。结论:**cc 是「单时间线 + 原地重来」(undo 哲学),pi 是「多时间线 + 分支文件」(git 哲学)**。若为 EM 设计,推荐 cc 模型 + 孤儿分支 GC + 树导航。

**状态**:未实施（仅调研报告）

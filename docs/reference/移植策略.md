# 移植策略

## 核心原则

1. **原始 Pi SDK 优先** — 能用 `@earendil-works/pi-coding-agent` 原生 API 解决的，不用 omp
2. **纯 JS 优先** — 优先选择不依赖 Bun / Rust 的方案
3. **遇到 Bun / Rust 必须先报告** — 不自行决定绕过或替代

## 决策流程

```
需要新功能
  │
  ├── 原始 Pi SDK 有？
  │     └── 是 → 直接用 ✅
  │
  ├── omp 有，且纯 JS？
  │     └── 是 → 评估后移植 ✅
  │
  ├── omp 有，但依赖 Bun API？
  │     └── 是 → 报告用户：功能描述 + Bun 依赖点 + Node 替代方案 → 用户决定 ⚠️
  │
  ├── omp 有，但依赖 Rust 原生层？
  │     └── 是 → 报告用户：功能描述 + 依赖的 crate/napi 模块 → 用户决定 ⚠️
  │
  └── 都没有 → 自己实现，报告方案 → 用户确认后动手 ⚠️
```

## Bun 依赖的判定

omp 代码中出现以下 API 时视为 Bun 依赖：

| API | 用途 | Node 替代 |
|-----|------|----------|
| `Bun.file().text()` | 读文件 | `fs.promises.readFile` |
| `Bun.write()` | 写文件 | `fs.promises.writeFile` |
| `Bun.sleep(ms)` | 延时 | `new Promise(r => setTimeout(r, ms))` |
| `Bun.randomUUIDv7()` | UUID | `crypto.randomUUID()` |
| `Bun.env.XXX` | 环境变量 | `process.env.XXX` |
| `Bun.deepEquals()` | 深度比较 | `assert.deepStrictEqual` |
| `Bun.fetch.preconnect()` | 预连接 | 可省略 |
| `YAML.parse()` / `YAML.stringify()` | YAML | `js-yaml` 库 |
| `JSONC.parse()` | JSONC | `jsonc-parser` 库 |
| `import { $ } from "bun"` | Shell | `child_process.spawn` |

## Rust 依赖的判定

omp 中使用 `@oh-my-pi/pi-natives` 的功能：

| 功能 | 依赖 | Node 替代 |
|------|------|----------|
| 文件搜索 (grep) | pi-natives | `child_process` + `ripgrep` CLI |
| Shell 执行 | pi-natives brush-shell | `child_process.spawn` |
| Worktree 隔离 | pi-natives iso backend | `child_process` + `git worktree` CLI |
| AST 操作 | pi-natives ast-grep | `child_process` + `ast-grep` CLI |
| 语法高亮 | pi-natives syntect | 不需要（Electron GUI） |
| 图片处理 | pi-natives image | `sharp` 库 |
| 终端 PTY | pi-natives pty | `node-pty`（Electron 已集成） |

**注意**：`@oh-my-pi/pi-natives` 本身是 N-API 模块，Node.js 可以直接 `require()`。问题是它需要编译对应平台的二进制（macOS ARM64/x64、Windows、Linux）。如果只是开发期用，可以直接 `npm install`；如果需要跨平台分发，编译链会增加构建复杂度。

## EasyMint 已安装的 omp 包

```
@oh-my-pi/pi-natives@17.0.8  ✅ 已安装（npm，N-API 二进制）
```

此包不依赖 Bun，可以在 Electron 的 Node.js 运行时中直接加载。

## 报告模板

当遇到需要报告的 Bun/Rust 依赖时，使用以下格式：

```
## 功能：[功能描述]

**来源**：omp 的 [文件路径]

**依赖**：
- Bun API：[列出具体 API]
- Rust/原生：[列出具体模块]

**Node 替代方案**：[具体替代方式]

**影响**：[对 EasyMint 的影响评估]

是否继续？
```

# 开发记录 2026-06-25

## 2026-06-25 更新 — v0.3.0


### ✅ Skill 注入机制改造

| 改动 | 说明 |
|------|------|
| 两层分级 | `EM_SKILLS`（EM 专用，仅 builtin）vs `BUNDLED_SKILLS`（ponytail 等第三方，全局优先/builtin 兜底） |
| 注入方式 | 内置 Skill 不再 seeding 到 `~/.claude/skills/`，改为直接扫 `resources/skills/`——CC 无法读取 EM 专用 Skill |
| 种子逻辑 | `seedBundledSkills` 只把 BUNDLED_SKILLS 装到全局（已有则跳过），EM 专用 Skill 永不泄露 |
| 前端展示 | SettingsDialog SkillsTab 加「EM 内置」分组，标记不可删 |
| 新增 ui-sync Skill | 用户表达新需求时自动触发，检查清单：是否追加 task、是否切 stage、何时调 MCP |

### ✅ Hook 校验系统

| 规则 | 说明 |
|------|------|
| building 前检查 | 其他任务有 building/evaluating 状态时拒绝，必须先完结 |
| done 前检查 | `set_project_stage("done")` 时所有任务必须完成或失败 |
| 顺序检查 | evaluating 必须 preceded by building；failed 必须 preceded by building/evaluating |
| canUseTool 白名单 | EM 自有 MCP 工具 bypass auto-mode 分类器 |

### ✅ Compact 体验优化

| 改动 | 说明 |
|------|------|
| 状态显示 | 自动 compact 时广播状态 + 设 busy，"正在整理会话..." 全程显示 |
| 输入框蒙版 | 毛玻璃遮罩 + "Mint 正在总结对话，请稍后…"，禁用输入 |
| 完成提示 | compact_boundary 后 toast "会话已整理完毕"（3 秒） |

### ✅ 会话历史

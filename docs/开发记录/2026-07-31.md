# 开发记录 2026-07-31

## 9. v3 UI 全面改版（2026-07-31）


### 9.1 布局与视觉体系

- **双栏布局**：三栏（44px 工具条 + 左面板 + 右侧面板）合并为 250px 固定侧边栏 + 主区，纯色差分层（无分割线）
- **Layer 色彩体系**：L0 Canvas → L1 Sidebar → L2 Content → L3 Card → L4 Elevated，阴影（xs/sm/md/lg）代替边框；`--color-surface*` 旧变量对齐层级色（去绿色调）
- **侧边栏**：项目名+菜单（新建/打开/重命名项目/新建窗口）、会话|文件 tabs、底部抽屉（任务/Issue/运行，点击外部关闭）、主题三模式
- **TabBar**：固定宽度 14em、常显关闭按钮、flex 压缩（min-width 60px）、marquee 滚动（min() 钳制：未超出不滚动）
- **消息区**：M/U 头像+来源标签、悬浮复制按钮、外层 32px+内层 32px 双重 padding 对齐输入卡片
- **会话列表**：今天/之前(7天)/更早分组、时间右侧同行、项目会话圆点/设计会话菱形点
- **主题切换**：View Transitions 扩散动画（startViewTransition + clip-path，mix-blend-mode normal 防掉帧）
- **编辑器**：Monaco 主题 CSS 变量化（--color-code-*/--color-monaco-*）、暖乳白色系、markdown 标题标准 token（本地 markdown-monarch.ts）、行号栏微调

### 9.2 上下文压缩与轮转（重点修复）

- **主动压缩**：ctxPct ≥ 阈值（默认 75%，设置滑块可调）→ agent:compact；ctxThresholdFiredRef 防重复
- **状态机修复**：主进程广播 type 'compact'（原 'manual' 与前端判断不匹配）；compacted 事件清除 compacting（原永不清除会锁死输入框）
- **轮转链路**：前端事件断链修复（onRotateCreate → onContextRotated）；Pi 原生摘要接入 summaryBuffer（原恒空，轮转从未执行）；轮转进度提示
- **rotation.ts**：轮转状态机独立模块（MAX_COMPACT/RotationState/finishRotation，RotationDeps 依赖注入）

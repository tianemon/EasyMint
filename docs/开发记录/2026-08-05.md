# 开发记录 2026-08-05

## 15. 方案收敛:Agent 模板模块 + 动态委派(2026-08-05)


> 关键结论:task 工具已完整支持 subAgent 单独配置 model/provider(阶段 2)。
> 群聊的"多 agent 长期会话 + 全量背景注入"过度复杂;收敛为主会话(Mint)+ task 动态委派 + 模板模块。

**设计要点**:
- **AgentTemplate 扩展**:agentType → string(开放自定义角色),加 `default`(默认模板标记)、`thinkingLevel`;executor 用模板的 prompt 作为子 agent system prompt
- **task 工具 agent 参数动态化**:由 `listTemplates()` 实时生成模板清单(名称+职责+模型),Mint 可见可用
- **模板编辑 UI**:设置→Agent 页:列表+表单(增删改);Mint 建模板工具 `create_agent_template`
- **群聊代码降级**:保留实验性,不继续投入;assign_to_agent/兜底语法转为 task 轻封装
- **实现 5 阶段**:A 模板扩展 B task 动态清单 + executor prompt C 模板 UI D Mint 建模板工具 E 群聊降级

> 注:原设计含"默认模板标记(default)"机制,实现时因"task 默认白板"语义确认而**删除**——不指定 agent 即标准子 Agent,无默认模板。详见 16.3。


## 16. 供应商/模板体验优化 + 工具注入增强(2026-08-05 下午)


> 本批为 Agent 模板模块落地后的体验收敛 + 工具对模型的可见性增强。

### 16.1 供应商列表修正

1. **删除火山引擎品牌**:Pi 无此 provider(硬编码加入,配置了也无法发消息);`provider-brands.ts` 移除 volcengine 条目
2. **OpenCode 图标**:官网 SVG(light-square)→ 250×250 透明 PNG,不再借用 deepseek 图标
3. **供应商下拉只显示 Pi 内置名称**:label 用 pi-init-static.ts 官方名(如 "Moonshot AI"、"Z.AI Coding CN"),去中文括号

### 16.2 自定义供应商表单重排

- 顺序:选择平台 → 名称 → API Key → Base URL → API 协议 → 模型列表 → 模型(默认) → 兜底 → 子Agent默认
- 模型列表占位符 `model-1/model-2/model-3`(原火山模型示例)

### 16.3 Agent 模板编辑权限收敛

- **Mint 模板只读预览**(始终强制官方提示词,seedDefaults 每次覆盖);其余内置模板(Builder/Mint-D/Evaluator)可编辑且持久(seedDefaults 保留用户版,不再重置)
- **task 默认白板确认**:不指定 agent = 标准白板子 Agent(无模板人设),executor 只在显式指定时查模板
- **删除默认模板死机制**:`default` 字段、`setDefaultTemplate`、`getDefaultTemplate` 全删(无调用方,且与"白板默认"语义冲突)
- **模板 tools 字段移除**:executor 固定全量工具集(`getBaseTools`),tools 从未生效,纯死配置

### 16.4 思考等级补全 + 全局设置

- 思考等级补全为 Pi 完整 7 档:`off / minimal / low / medium / high / xhigh / max`,聊天页与模板页统一显示"中文(英文)"
- **全局思考等级**(设置→模型组):存 em-settings `chatThinkingLevel`,仅作新聊天会话初始默认(方案 B,聊天下拉临时切换不持久化)
- 加固:启动时 store 异步加载竞态——用户未手动切换时跟随全局值(`userChangedThinkingRef`)

### 16.5 系统提示词与工具可见性

- **Task 委派分工总则**(prompts.ts):默认白板 vs 指定模板的认知;查资料/读代码用白板,写代码/验收用 builder/evaluator
- **工具 promptSnippet/Guidelines**:task、create_agent_template、productTools 全部补 snippet(进 Pi 提示词 `Available tools` 清单);task/建模板补 promptGuidelines(进 Guidelines 节)
- **MCP 工具补 snippet**:mcp-adapter 对每个 MCP 工具生成描述首行截断(80 字符),tavily/playwright/codegraph 等进清单
- **`[1M]` 清洗移除**:Pi 用 `contextWindow` 字段表达 1M 上下文,模型名无 `[1M]` 后缀——Claude SDK 时代遗留的 `replace(/\[1M\]$/, "")` 全部删除(pi-init/executor/group-session)

### 16.6 类型收紧

- pi-sdk.ts wrapper 返回精确类型(ModelRuntime/SessionManager/SettingsManager/DefaultResourceLoader),pi-session 去 `as any`

### 16.7 已知缺陷(未修,记录)

1. 群聊 + 自定义供应商:模板 provider 解析链未验证,可能报"无可用模型"(群聊试验性,后置)
2. 群聊成员无 task 工具:tools 字段删除后 buildGroupTools 传空数组(群聊试验性,后置)
3. MCP 工具不进提示词清单:已修(snippet),但工具描述过长时 snippet 截断 80 字符
4. 内置模板 id 硬编码前端(BUILTIN_IDS):Pi 升级加模板会失配,低风险
5. 供应商下拉纯英文名:无中文提示,非技术用户可能认不出(用户要求如此,暂缓)

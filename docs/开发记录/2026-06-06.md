# 开发记录 2026-06-06

## 2026-06-06 更新


### ✅ 新增实现

| 功能 | 说明 |
|------|------|
| 暗色/亮色/自动主题 | `[data-theme="dark"]` 纯黑白灰配色，LeftToolbar 切换按钮，session 级持久化 |
| 设计 Token 统一管理 | `index.css` 集中所有颜色变量（~95个），TSX 零硬编码 hex，color-mix 引用链修复 |
| 上下文轮转系统 | `getContextUsage()` 检测 → ≥60% 自动总结 → 新 Tab 接手，旧会话归档到时钟按钮 |
| 上下文用量显示 | 工具栏显示百分比，per-session 缓存到 `~/.easymint/session-cache/` |
| Markdown 渲染 | `marked` 转 HTML，代码块独立容器 + 复制按钮 |
| MCP seed 机制 | `seedDefaultMcp()` 内置 codegraph/playwright/tavily/image-vision |
| image-vision prompt 参数 | `describe_image` 支持可选 `prompt` 自定义提示词 |
| 会话归档 | `archived-sessions.json`，时钟按钮弹出列表，可继续聊天 |
| Mint 按钮 | 签名字体 + 彩虹流光效果，点击优先拉起已有会话 |
| 鱼骨图电流效果 | SVG linearGradient 彩虹渐变动画 |
| 产品功能指引 Skill | `easymint-guide` 内置 Skill，口语化描述程序功能入口 |
| 操作封装层设计 | `docs/基础操作封装层-设计方案.md`，双轨合一 Architectual Design |

### 🐛 Bug 修复

| 问题 | 修复 |
|------|------|
| Skill 描述缺失 | YAML 解析兼容 CRLF 换行 |
| 内置 MCP 无 seed | `seedDefaultMcp()` 首次启动写入配置 + image-vision 源文件复制 |

### 📐 架构重构

| 改动 | 说明 |
|------|------|
| 取消 Orchestrator | 删除默认模板，Mint 规则 10 改为亲自驱动 Task(builder) → Task(evaluator) |
| Agent 模板只读 | 去掉新建/编辑/删除表单，系统管理模板 |
| 叶子按钮 → Mint 按钮 | 改名 + 改签名字体 + 流光动画 + 优先拉起已有会话 |
| 所有按钮虚线 → 实线 | 全局统一 |
| 消息时间戳移除 | SDK `SessionMessage.message: unknown`，不暴露消息级时间 |

### 🔧 系统提示词更新

- **规则 10 重写**：Mint 亲自执行任务，不再交给 Orchestrator
- **新增任务执行流程**：读 task.json → Task(builder) → Task(evaluator) → 判断 → 下一任务
- **新增 easymint-guide Skill 引用**：用户问产品使用问题时调 Skill

### 📦 依赖变更

- **新增**：`react-markdown`、`remark-gfm`、`marked`
- **移除**：`react-markdown` + `remark-gfm`（改用 `marked`）

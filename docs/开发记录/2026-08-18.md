## 自定义添加模型功能（ProviderSettings）

- 需求：内置供应商模型下拉下方增加"添加模型"输入框——补充 SDK 列表外的模型（如新上线 glm-5.3），SDK 升级自带同样模型时去重
- 实现：新增 `extraModels` 字段（ProviderConfig，独立持久化）+ 输入框/添加按钮/标签（可移除）
  - `availableModels = [...SDK models, ...extraModels]` 合并去重（new Set）
  - 编辑打开时 extraModels 从 config 读取，不受 loadModels(Pi 拉取)覆盖
- **bug 修复**：初版 extraModels 用 state 不持久化——重新编辑时 loadModels 覆盖 models 丢失添加的模型；改为独立字段持久化

# 开发记录 2026-07-28

## 2026-07-28 更新 — Pi SDK 迁移收尾


第五步（提交 `4470aaa`）：Claude SDK → Pi SDK 迁移完成后的系统性修复。

### 流式输出修复

| 改动 | 说明 |
|------|------|
| turn 边界信号 | `message_start` 作为新 assistant turn 开始的信号，前端据此记录 `turnEntryIdxRef` |
| `replaceAiEntriesFrom` | 新增 store 方法，按 turn 边界替换 entries，保留旧 turn 内容 |
| `messageToBlocks` 统一转换 | Pi 的 `toolCall` 类型映射为前端的 `tool_use`，thinking 块正确提取 |
| 跨 turn 覆盖修复 | 多轮工具调用（LLM → tool → LLM）不再互相覆盖，所有 turn 在同一气泡内追加 |

### 权限系统修复

| 改动 | 说明 |
|------|------|
| `displayToolName` 修复 | `wrapToolWithPermission` 不再用变形后的名字（如 `Bash(echo hello)`）传 `canUseTool`，改用原始名匹配 |
| 内置 MCP 白名单 | 10 个 `easymint-ui` 工具加入 `SAFE_TOOLS`，免审批（Pi SDK `customTools` 无 `mcp__` 前缀） |
| `tool_execution_start` 处理 | `event-bridge` 新增，所有工具执行时状态栏都显示工具名 |
| 权限 UI 修复 | `PermissionPrompt` 加日志，工具名匹配修正 |

### 角色模板修复

| 改动 | 说明 |
|------|------|
| 模板 vs 默认 prompt 互斥 | `buildSystemPrompt`：选模板时用模板 prompt **替代**默认 Mint prompt，不再叠加两套身份 |

### 路径修正

| 文件 | 错误路径 | 修正 |
|------|---------|------|
| `process-service.ts` | `<project>/.easymint/run.json` | `<project>/.easymint/run.json` |
| `issue-service.ts` | `<project>/.easymint/issues.json` | `<project>/.easymint/issues.json` |
| `issue-service.ts` | `<project>/.easymint/` dir | `<project>/.easymint/` |

全局数据（settings、sessions、templates）仍正确使用 `~/.easymint/`。

### 跨 Tab 事件隔离

| 改动 | 说明 |
|------|------|
| `event.runId` 短路修复 | `PiChatEvent` 没有 `runId` 字段，原 `event.runId && ...` 永远为 false，导致 `chatId` 过滤失效。改为 runId/chatId 独立判断 |
| `onChatSession` 过滤 | 无 `currentChatRef` 且无 `existingSid` 时拒绝所有事件 |

### 状态栏优化

| 改动 | 说明 |
|------|------|
| 文本到达自动清除 | 纯文本 `message` 事件到达时，自动清除 "正在请求..." 和旧工具标签 |
| 工具标签不残留 | 工具完成后 LLM 继续返回文本时，状态栏不再显示已完成的工具名 |

### 工程清理

| 改动 | 说明 |
|------|------|
| 删除 `claude-detector.ts` | Claude CLI 检测不再需要 |
| 删除 `notify.ts` | Pi 用 `session.sendCustomMessage` 替代 |
| `pi-chat-event.ts` 类型移除 | 事件类型统一在 `event-bridge.ts` 中定义 |
| Claude SDK 依赖移除 | `@anthropic-ai/claude-agent-sdk` 完全卸载 |

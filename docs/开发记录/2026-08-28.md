## 字号统一管理：--ui-scale / --chat-scale 双滑杆

- 用户反馈：设置中字号只对会话列表/聊天页生效，文件列表等 UI 不生效 → 需求「彻底统计所有文字大小、统一管理」。方案确认（落盘 `docs/design/UI字号统一管理方案.md`）：新增独立 UI 字号滑杆（百分比）、聊天字号滑杆保留、硬编码全量替换
- 机制：`:root` 新增 `--ui-scale`（UI 缩放系数）；Tailwind 4 工具类 `.text-xs` 等引用同名 `--text-xs` CSS 变量，`index.css` 后定义 `calc(px × var(--ui-scale))` 覆盖默认值——默认 100% 视觉零变化，标准类/任意值类（`text-[length:var(--text-11)]`）全部纳入缩放（构建产物验证）
- 新增 `--text-3xs(9)/--text-4xs(8)/--text-11(11)/--text-2xl(24)` 档位；170+ 处 `text-[9/10/11px]` → 语义变量（38 组件）；`FileTreePanel` 内联 `fontSize:'12px'`、`GlowGroupManager` 8px、`Sidebar`/`ChatBubbleActions` SVG 内文字（attribute 不解析 var()，改 style 内联）清零；Monaco 编辑器字号实测 `--text-sm` 并订阅滑杆 `updateOptions`
- 第二轮回访：会话列表归属调整——`--chat-list-size` 改乘 `--ui-scale`（UI）；聊天区 5 个语义变量（body/detail/caption/code/meta）改乘新增 `--chat-scale`（聊天），原 caption/code/meta 误挂 `--ui-scale` 纠正
- 聊天滑杆 1-6 级 → 百分比（`chatFontScale` 0.9~1.3）：旧 `chatFontLevel` 自动映射迁移（3级→100% 等），首启落盘新字段；主进程 store.ts 类型/落盘补 `chatFontScale`，保留旧字段兼容读取
- 修复既有缺陷：`loadFromElectron()` 只恢复值不写 CSS 变量 → 重启回落默认值，启动时同步应用（双滑杆共用）
- 环形圈 8px 百分比文字：UI 放大 130% 时 10.4px 溢出 20px 圆环 → `clamp(8px, var(--text-4xs), 10px)` 限幅保护（用户确认「加保护」）
- 字号模型结论（专业建议）：保持「字体驱动布局流动」（放大→容器自适应）为主流可访问性做法，不为抗波动固定容器；仅固定尺寸容器×动态文字角落做保护
- 验证：typecheck / eslint / 构建产物（标准类 + 任意值类引用变量、calc 定义输出）全过

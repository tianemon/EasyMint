## 压缩弹窗修复 & 发版 v0.11.2

### 用户反馈

- 75% 上下文未触发压缩弹窗
- 压缩后发消息无响应/不落盘；压缩蒙版长时间显示但 jsonl 无压缩条目（实际没压缩）；Mint 记忆"没被压缩"
- 手动压缩成功（只留最近 20 轮——SDK 正常策略）

### 排查过程

1. **75% 不弹窗**：ctxThresholdFiredRef（防重复弹窗标记）残留——会话切换（onChatSession 不重置）、弹窗 onClose（不 rearm）、压缩失败/跳过（pct 未回落 <55 不重置）→ 修复：done/会话切换重置 + onClose rearm
2. **压缩后无响应**（用户提供日志）：
   - `prompt error: Cannot submit a prompt while compaction is in progress`——SDK 防护（压缩中拒绝新 prompt）
   - `compact failed: Error: Compaction cancelled`——killChat（用户结束会话）→ dispose → abortCompaction 取消压缩
   - 用户确认：输入无响应 → 手动结束会话重开 → 正常
3. **蒙版误导**（jsonl 无条目但显示"正在整理"）：手动路径 agent-service.compact() 在 SDK 调用前**预广播** type="compact" → 前端立即显示蒙版——SDK 若卡在 compact() 开头 `await this.abort()`（waitForIdle 挂起）则 compaction_start 不发、压缩未开始，但前端已显示
   - 修复：**显示跟随 SDK 真实状态**——type="compact" 只标记手动来源；蒙版统一由 compacting 事件（SDK compaction_start）触发；SDK 未开始则不显示
   - 120s 超时兜底：只恢复界面显示，不中断 SDK 压缩（用户明确不要强制中断）

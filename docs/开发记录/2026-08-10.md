# 开发记录 2026-08-10

## 20. Pi 配置目录体系统一 & Claude SDK 遗留清理（2026-08-10）

> 背景：EM 与 Claude Code 解耦后仍有隐式耦合未闭环——Pi SDK 默认读取项目的 AGENTS.md/CLAUDE.md 与 `.pi/` 资源；agentDir 双目录（`pi/` + `pi-agent/`）职责分裂；`~/.easymint/` 下积累大量 Claude SDK 时代遗留。

### 20.1 排查结论（源码实证）

- **Pi 默认目录体系**：全局 `~/.pi/agent`（可用 `PI_CODING_AGENT_DIR` env 或 `agentDir` 参数覆盖）+ 项目级 `<cwd>/.pi/`（CONFIG_DIR_NAME）+ 上下文文件 AGENTS.md/CLAUDE.md（agentDir + cwd 逐级向上扫描）
- **EM 映射方式**：env 指向 `~/.easymint/pi-agent`（ModelRuntime 用）+ 显式参数指向 `~/.easymint/pi`（resourceLoader 用）——两个"全局目录"并存
- **隐式耦合**：`noContextFiles` 未传 → 项目 CLAUDE.md/AGENTS.md 仍注入 Mint 系统提示词（EasyMint 项目自己的 CLAUDE.md 就是实证）；`noExtensions/noPromptTemplates/noThemes` 未传 → 项目 `.pi/` 资源会被加载（trusted 时）
- **遗留文件**：`~/.pi/agent/`（含旧 deepseek 配置）、`~/.easymint/settings.json`（含 deepseek API key，无代码引用）、`~/.easymint/.claude.json`（Claude 全局配置，含 userID/machineID）、`telemetry/`（32 个 Claude SDK 遥测事件）、`projects/`（Claude SDK 会话）、`commands.json`（Claude 命令迁移遗留，全 app 无引用）、147 个 `__new_` 孤儿临时文件（早期原子写残留）

### 20.2 用户决策

1. **`~/.easymint` 替换 `~/.pi` 层级**——不想要 `.easymint` 下再有 `pi/`、`pi-agent/` 子目录；严格对应 Pi 默认 `~/.pi/agent` 结构 → agentDir 统一为 **`~/.easymint/agent/`**
2. 清理清单（11 项 + 2 项二次筛选）全部确认后删除

### 20.3 实现改动

| 文件 | 改动 |
|---|---|
| `app/main/index.ts:19-27` | `PI_CODING_AGENT_DIR` → `~/.easymint/agent`；追加一次性迁移（`pi-agent/models-store.json` → `agent/`，幂等） |
| `app/main/services/agent-service.ts:392` | `getAgentDir()` → `~/.easymint/agent`（8 个调用方随动） |
| `app/main/services/pi-session.ts:62-70` | resourceLoader 补 `noContextFiles / noExtensions / noPromptTemplates / noThemes: true`（连同已有 `noSkills`，Pi 资源发现全关） |

**资源流向（改后）**：Mint 上下文 = 100% EM 自己组装（Mint 提示词 + EM skills + env/profile 动态 section），项目 CLAUDE.md 对 Mint 不再生效。

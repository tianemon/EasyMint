# 开发记录 2026-06-04

## 2026-06-04 更新


### ✅ 新增实现

| 功能 | 说明 |
|------|------|
| Skill 管理系统 | 扫描/导入/隐藏/内置 seed，与 Claude Code 共用 `~/.claude/skills/` 目录 |
| MCP 管理系统 | 与 Claude Code 共享 `.claude.json` 配置，API Keys 注入，设置面板 UI |
| 上传缓存管理 | 手动清理列表（按时间/大小排序），60天/10GB 自动清理 |
| 图片上传 | 粘贴/拖拽/多选，分离式附件预览，点击查看原图 |
| 文档上传 | 按类型显示彩色图标，混合附件区 |
| 回旋镖/鱼骨进度面板 | chevron → fishbone 六阶段指示器，hover 展开，含注释参数 |
| Monaco Editor | 替换 CodeMirror，VS Code 同款引擎，HTML/CSS/JS/TS/JSON/Markdown 原生支持 |
| 万能推进按钮 | 无会话时自动创建并发送提示词，有会话则激活并发送 |
| 项目阶段检测 | `refreshAll` 自动从文件推导六阶段（需求→技术选型→初始化→规划→开发→完成） |
| setupeComplete 双源兜底 | localStorage + em-settings.json 双重检查，防 Electron userData 迁移丢失 |

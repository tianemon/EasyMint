## 2026-06-22 更新 — v0.2.0


### 项目重命名
- 新增 `project:rename-exec` IPC，LeftToolbar「+」→「重命名项目」入口
- 流程：`fs.cpSync` 完整复制项目 → 复制 session → 更新 projects.json → `app.relaunch()` → 启动钩子 `fs.rmSync` 删旧
- 纯 Electron + Node.js，零外部依赖，跨平台
- 新增 `rename_project` MCP 工具（`builtin-mcp.ts`），Mint 可调用
- 二次确认弹窗（`window.confirm`），提醒用户 EM 将关闭

### 项目管理增强
- 新增 `project:import` IPC，「打开项目」弹窗加「浏览文件夹…」按钮，首页加「打开已有目录」入口
- 新增 `project:update` IPC + `store.updateProject()` + `project-service.update()`，支持路径变更时自动 `fs.renameSync` 迁移 SDK session 目录
- TitleBar 目录删除时红色提示「重新定位」，ProjectListPage 同样入口
- 移除启动时孤儿 SDK session 目录自动清理（后续做会话管理）

### Mint 提示词优化
- 生命周期加闭环：`done → 需求变更 → developing → 追加 task → 循环`
- 规则 4 决策树简化为 ①②：① 单文件微调 ≤ 20 行 → 直接改；② 其余 → 委派 Builder + 更新 UI
- `<keep_ui_alive>` 指令：任何代码改动都必须更新 UI 进度
- UI 工具解耦：`set_task_status` / `set_project_stage` 不再绑定 Builder，自行编码也调用
- `show_confirm_dev` 允许 done 后追加 task 时再次调用
- 旧「2 个独立功能」表述替换为「单文件微调 ≤ 20 行」

### UI 改进
- Fishbone 进度条全部完成时横轴亮色渐变（`allDone → url(#fishbone-current)`）
- TitleBar 简化为纯状态展示（项目名 + 目录删除时重新定位）
- Claude Code 和项目模板 `CLAUDE.md` 加 SVG 图标优先规则
- 去掉空 try/catch 遗留（agent-templates / mcp-service / session-cache / session-service / skill-service / system-prompt-manager / upload-cache / ipc-handlers）

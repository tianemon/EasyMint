## 20. v0.6.6 后 UI 体验优化 + 运行面板链路 + 确认按钮 + 解耦（2026-08-09）


> 提交 `6c7021c`（含全部 UI 改动）+ `12a002a`（MCP 修复）。按实现顺序记录。

### 20.1 Shell 胶囊背景修复

- 根因：`--color-info-soft` 缺失于 `@theme`（Tailwind v4 只在 @theme 注册的 token 才生成工具类）→ 亮色下 Shell 胶囊 `bg-info-soft` 无背景，而 Agent 胶囊（success-soft）正常
- 修复：`index.css` 三处补全 `info-soft`(10%)/`info-high`(20%)/`success-high`——亮色 @theme、亮色 :root、暗色三套

### 20.2 侧边栏「任务」按钮呼吸灯

- 需求：任务实际被 Agent 执行（任务行绿色转圈 `animate-spin`，即 `taskExecutions` running）时，任务按钮底色呼吸提醒
- 实现：`Sidebar.tsx` 判定 `Object.values(taskExecutions).some(e => e.status === "running")` → 按钮加 `task-breathing` 类；`index.css` 呼吸动画（底色明暗 10%↔30% + 柔和光晕，2.8s，亮色浅绿/暗色灰白）
- 踩坑：`@keyframes` 写在 `:root {}` 内会被浏览器忽略（必须顶层）——曾导致动画挂上但背景不动

### 20.3 设计会话模板错配（Mint-D 用成 Mint）

- 根因：ProjectPage 渲染 ChatPanel 未传 `isDesigner`，ChatPanel 发送时 `tabs.find()` 反查（条件 `!t.sessionId && !existingSid` 匹配所有新 tab）——多个未发消息新 tab 并存时错配到开发会话
- 修复：`isDesigner` 从 props 直传（`isDesigner ?? tab?.isDesigner` 兜底）；tab-store 主进程备份补 `isDesigner` 字段（防合盖恢复丢标记）

### 20.4 内置模板权限体系

- 新规则：Mint/Mint-D **完全不可修改**（只读浏览）；Builder/Evaluator **仅可改供应商/模型/思考等级**；自定义模板完整可编辑
- 主进程（agent-templates.ts）：`updateTemplate` 对锁定模板 throw、受限模板**过滤输入**（只接收 provider/model/thinkingLevel）；`deleteTemplate` 拒绝内置 4 个
- 前端：锁定模板只显示「浏览」；受限模板进受限表单（名称/描述/prompt 只读展示含系统提示词）；统一走 TemplateForm（删除独立预览弹窗——原弹窗 `bg-bg` 无效类名导致透明背景）；`Select` 组件补 `disabled` 支持
- 排序：内置模板 DEFAULTS 调整 Mint-D 到第二位（seed 每次启动按 DEFAULTS 重排）

### 20.5 新建项目下拉框收不回

- 根因：StepComponents 自定义 Select 的 mousedown 外部关闭 handler 未排除触发器按钮——点按钮收菜单时 mousedown 关闭+同步 flush+click 翻转（open 闭包已是 false→再开），永远关不上
- 修复：handler 加 `btnRef.contains(e.target)` 排除（触发器交给 onClick toggle，对齐全局 Select.tsx 的 inTrigger 处理）

### 20.6 侧边栏底部按钮

- 顺序：任务 / Issue / 运行 → **任务 / 运行 / Issue**（抽屉箭头 ptr 映射同步）
- 视觉：去掉按钮间 1px 分割线（原 `border-left`）；hover 整块亮起（`sidebar-active` 同色）+ 图标放大，active 阴影+加粗图标区分

### 20.7 run.json 链路闭环（运行面板）

- 需求：用户说「新增 xx 运行命令」时 Mint 应能响应，且写完后面板自动刷新
- 提示词（prompts.ts）：run.json 说明重写——明确"左侧运行面板的一键启动配置"、响应需求时机（不必等任务全部完成）、platform 合法值域
- 主进程（process-service.ts）：`ensureRunJsonWatch`——fs.watch 盯 `<项目>/.easymint/run.json`，变化广播 `process:run-json-changed`（按项目路径防重注册）
- 前端：RunPanel 订阅广播自动重新 detect；preload + 类型补 `onRunJsonChanged`

### 20.8 用户 PATH 注入（GUI 运行根治）

- 根因：GUI 应用由 launchd 启动只继承最小 PATH（/usr/bin:/bin:...），不含用户 shell 配置的 flutter/node 路径 → 运行面板命令 command not found 秒退
- 修复：`app/main/utils/user-path.ts`——启动早期 `zsh -lic 'print -r -- $PATH'` 提取用户完整 PATH 注入 `process.env.PATH`（3s 超时、失败不阻塞、进程级一次、仅 macOS；Windows GUI 继承注册表无需）

### 20.9 运行面板按钮区布局

- 原问题：运行中一行 4 个按钮（停止/重启 flex-1 文字 + 日志/打开图标）在窄抽屉里挤压，停止文字竖排
- 修复：文字按钮只留「停止」（flex-1），重启/日志/打开 URL 全部 w-6 图标化（shrink-0）

### 20.10 控制台弹窗被限制在运行面板

- 根因：`.sb-drawer` 常驻 `transform: scaleY`（开合动画）→ fixed 弹窗（LogOverlay）相对 transform 祖先定位，被困在抽屉内
- 修复：`createPortal(..., document.body)` 挂 body 彻底脱离（对齐 Select 组件处理）

### 20.11 控制台"等待输出"（快速命令日志丢失）

- 根因：进程退出时前端 `loadStatus()` 拉主进程状态——但主进程内存 map 已删该命令 → `output: []` → 覆盖前端已有日志成空
- 修复：`loadStatus` 主进程返回空输出时保留前端已有 logs（`st.output.length > 0 ? st.output : cur.logs`）

### 20.12 确认开发按钮失效

- 根因：`show_confirm_dev` 工具广播 `agent:confirm-dev` 但前端**未订阅**——按钮全靠 `!busy && 消息推断`，Mint 回合中（busy=true）调用工具时按钮被 busy 条件吞掉
- 修复：preload 补 `onConfirmDev`/`onNewProject` 订阅 → ChatPanel 广播直连 flag（不受 busy 影响）+ 消息推断兜底（历史恢复）；点击消费 = 清 flag + 从消息移除 show_* 条目（打断/回合结束不复活，临时按钮语义）
- 连带修复 `loadMcpTools` 空结果不缓存（12a002a：某次加载全失败时 toolsCache 永久为 []，后续所有会话无 MCP）

### 20.13 EM 与 Claude Code 彻底解耦

- MCP 配置：`~/.claude/.claude.json` → **`~/.easymint/mcp.json`**（一次性迁移导入旧配置；seedDefaultMcp 迁移导入标记 changed——曾因迁移覆盖全部默认服务器导致文件不落盘）

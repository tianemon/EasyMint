# 内容便签设计

> 状态：已确认方案（2026-08-01），待开发
> 方案：独立 pin-store + 全局元数据文件（方案 A）

## 1. 需求

AI 总结了一大段内容后，随着对话进行该消息被顶到上面，查看需要往上翻。需要把内容"钉"成悬浮便签卡片，固定在聊天界面上随时查看。

### 已确认的 6 项决策

| 维度 | 决策 |
|------|------|
| 位置 | 悬浮便签卡片，可拖动 |
| 数量 | 多张并存，各自独立拖动/关闭 |
| 持久化 | 会话级——切会话看不到，切回恢复；上下文轮转后便签留在旧会话 |
| 来源 | 两个入口：① 消息 hover 按钮钉整条 ② 选中片段钉住 |
| 形态 | Markdown 渲染 + 只读快照（钉住后不可编辑） |
| 可见范围 | 仅聊天界面（便签层挂在 ChatPanel 内，切到编辑器 tab 不显示） |

## 2. 数据模型

```ts
interface Pin {
  id: string;        // 唯一 ID（`pin_${Date.now()}_${random}`）
  content: string;   // Markdown 快照（整条消息为全部 text entry 合并；选区为纯文本）
  title: string;     // 内容首行去 Markdown 符号后前 20 字
  x: number;         // 相对 ChatPanel 根容器左上角 px
  y: number;
  createdAt: number;
}
```

**存储**：`~/.easymint/session-pins.json` → `Record<sessionId, Pin[]>`

- 与会话元数据（pinned-sessions / session-titles 等）同位置、同 `readJson`/`writeJson` 模式
- 便签数量少（个位数），每次变更全量覆盖写，无增量协议

## 3. 架构

```
ChatPanel（absolute inset-0 根容器）
 └─ PinLayer（absolute inset-0, pointer-events-none, z-30）
     ├─ PinCard × N（pointer-events-auto）
     │    ├─ 标题栏：📌 + title + ×（拖动把手）
     │    └─ 内容区：TextBlockView 渲染 content 快照
     └─ 选区钉住浮动按钮（选中文字时出现在选区附近）

pin-store (zustand) ←→ IPC "pin:get / pin:set" ←→ pin-service ←→ ~/.easymint/session-pins.json
```

### 主进程：`app/main/services/pin-service.ts`（新增）

平面函数模块，参照 session-service.ts 模式：

- `getPins(sessionId): Pin[]` — readJson 读取，缺失返回 `[]`
- `setPins(sessionId, pins): void` — 全量覆盖写（空数组时删除该 key）

### IPC 与 preload

- `ipc-handlers.ts` 注册 `pin:get` / `pin:set`
- preload 暴露 `window.electronAPI.pin.get(sessionId)` / `.set(sessionId, pins)`
- `app/renderer/vite-env.d.ts` 补充 `pin` 类型声明

### 前端：`app/renderer/src/stores/pin-store.ts`（新增）

```ts
interface PinState {
  pinsBySession: Record<string, Pin[]>;
  loadPins: (sessionId: string, pins: Pin[]) => void;
  addPin: (sessionId: string, content: string) => void;
  removePin: (sessionId: string, pinId: string) => void;
  movePin: (sessionId: string, pinId: string, x: number, y: number) => void;
  bringToFront: (sessionId: string, pinId: string) => void;  // 移到数组末尾 = z 最高
  migrateSession: (oldSid: string, newSid: string) => void;  // 临时 sid → 真实 sid
}
```

**持久化时机**：add / remove / bringToFront 后立即调 `pin.set` 全量写；拖动中只更新内存（movePin），pointerup 时才 `pin.set`——避免拖动 60fps 高频写盘。

**title 生成**：`content` 首行去掉 `#`、`*`、`-` 等 Markdown 符号，取前 20 字；空内容兜底"便签"。

## 4. 组件设计

### `app/renderer/src/components/PinLayer.tsx`（新增）

- 渲染在 ChatPanel 根 div 内末尾，`absolute inset-0 pointer-events-none z-30`（低于图片 lightbox 的 z-50）
- props：`sessionId`、`scrollRef`（消息滚动容器，用于选区监听）
- 自身 ref 测量容器尺寸：新便签默认定位 + 渲染 clamp
- **新便签默认位置**：右上角 `x = 容器宽 - 336, y = 16 + (已有数量 % 5) × 24` 错开堆叠
- **渲染 clamp**：`x = clamp(0, pin.x, 容器宽 - 320)`，窗口变小后便签不丢失

### PinCard（PinLayer 内部组件）

- 宽 320px，`absolute`，`left/top = clamp 后的 pin.x/pin.y`
- 标题栏拖动：pointerdown 记录起点 → pointermove 更新 movePin（clamp 在容器内）→ pointerup 持久化；用 pointer capture 保证拖出卡片不丢
- 内容区：复用 `TextBlockView`（ChatBlocks.tsx，需 export）渲染快照，`max-height: 40%` 容器高，超出滚动
- 点击卡片任意处 bringToFront
- × 关闭即删除（removePin，无二次确认——重新钉成本低）

### 入口 1：消息钉住按钮

- `MemoChatMessage` 中 `CopyBubbleBtn` 旁加 `PinBubbleBtn`（图钉 SVG 图标，同 hover 浮现样式）
- 用户消息和 AI 消息都加
- 内容 = 现有 `copyText` useMemo（text entries 合并）
- 点击反馈：图标短暂变勾（复用 CopyBubbleBtn 的 copied 模式）
- MemoChatMessage 新增 prop `onPin: (text: string) => void`，ChatPanel 传入 `pinStore.addPin(sidRef.current, text)`

### 入口 2：选区钉住

- 监听消息滚动容器 `scrollRef` 的 mouseup：
  - `window.getSelection()` 非空且选区在容器内 → 在选区 `getBoundingClientRect()` 末尾位置显示浮动"📌 钉住"小按钮
  - 选区为空或点击别处 → 隐藏
- 点击 → `addPin(sid, selection.toString())` → `selection.removeAllRanges()` 隐藏按钮
- **已知简化**：`selection.toString()` 是纯文本，丢失 Markdown 格式（列表/标题符号不保留）；渲染时按纯文本 + `breaks: true` 换行展示，可接受

### ChatPanel 集成（修改点）

1. 根 div 内末尾渲染 `<PinLayer sessionId={sidRef.current} scrollRef={containerRef} />`
2. `useEffect [sid]`：`window.electronAPI.pin.get(sid)` → `loadPins`（新会话临时 sid 返回空）
3. 现有 `useEffect [existingSid]` 临时 sid 迁移逻辑中追加 `usePinStore.getState().migrateSession(oldKey, newKey)`
4. `MemoChatMessage` 传 `onPin`

## 5. 错误处理

| 场景 | 处理 |
|------|------|
| `session-pins.json` 损坏/不存在 | 主进程 readJson try/catch fallback `[]`（现有模式） |
| 渲染进程 `pin.get` IPC 失败 | catch → `console.error` + loadPins 空数组 |
| 窗口缩小小于便签坐标 | 渲染 clamp 兜底，不修改持久化值 |
| 会话删除 | 便签数据保留在 json 中（与会话元数据一致，不级联清理；量极小） |

## 9. 迭代修改 v2（2026-08-01，用户反馈 3 项）

### 9.1 气泡按钮常驻显示

`CopyBubbleBtn`/`PinBubbleBtn` 从 `opacity-0 group-hover:opacity-100` 改为常驻浅色（`text-text-secondary`，hover 加深 `text-text-primary`）。右键菜单作为补充入口。

### 9.2 消息右键菜单（替代选区浮动按钮）

- **触发**：任何消息气泡上 `onContextMenu`（preventDefault），菜单定位在鼠标处
- **菜单项**：复制（有选区复制选区、无选区复制整条）、全选（Range 选中整条消息文字）、钉住（有选区钉选区、无选区钉整条）
- **删除**：现有 mouseup 选区检测 + 浮动"钉住"按钮逻辑
- **组件**：轻量通用 `ContextMenu`（state `{x, y, items}` + fixed 定位 + 点击外部关闭），ChatPanel 内使用；SessionHistory 旧菜单不动

### 9.3 选区钉住 Markdown 还原

`selection.toString()` 是纯文本丢格式。改为从选区 DOM（`range.cloneContents()`）提取 block 结构（列表 → `- `/`1. `、标题 → `#`、代码块 → ``` 包裹、引用 → `> `、inline 加粗 → `**`）再拼 Markdown。提取 DOM 部分在组件内，结构→Markdown 转换是纯函数（可单测）。

### 9.4 便签大小可调

- `Pin` 加可选字段 `width?: number; height?: number`（缺省宽 320、高 auto）
- PinCard 右下角 resize 手柄（`cursor-se-resize`），拖动改尺寸：宽 clamp 240-560，高 clamp 100-容器 80%；内容超高滚动
- 拖动结束 persistPins（与位置拖动同模式）
- 类型同步 4 处：pin-service / preload / vite-env.d.ts / pin-store

## 10. 迭代修改 v3（2026-08-01，用户反馈：书签式便签）

### 10.1 需求

便签新增**贴纸形态**：拖到边缘自动吸附折叠成竖条贴纸（也可点最小化按钮折叠）；点贴纸展开回卡片。每张便签有固定颜色（贴纸/卡片同色标识，现存便签互不重复）；同边贴纸默认堆叠，也可拖动单独吸附。

### 10.2 数据模型（Pin 新增 3 个可选字段）

```ts
colorIdx?: number;   // 调色板索引 0-7；addPin 时分配现存未使用的最小索引，用尽则 count%8 兜底
minimized?: boolean; // true = 贴纸态（贴纸渲染，卡片隐藏）
edge?: "left" | "right"; // 吸附边（minimized 时有效）
```

- minimized 时：`y = -1` 表示贴纸未单独定位（渲染层按同边堆叠槽位算 y）；拖动贴纸后存具体 y
- 展开（点击贴纸）：minimized=false、edge 清除，卡片出现在贴纸边内侧（x = 边缘 16px，y = 贴纸 y）

### 10.3 调色板（8 色，Tailwind 内置色，className 全量映射防 purge）

sky-500 / emerald-500 / amber-500 / purple-500 / rose-500 / teal-500 / orange-500 / indigo-500

- 贴纸：色块背景 + 白色图钉图标
- 卡片：标题栏左侧 3px 色条（同色）
- 旧数据无 colorIdx → 渲染按 `index % 8` 兜底

### 10.4 交互

- **自动折叠**：卡片拖动中 x ≤ 8 → 吸附左边缘；x + 宽 ≥ 容器宽 - 8 → 吸附右边缘；minimized=true + edge 设置 + y=-1（堆叠槽位）
- **最小化按钮**：标题栏加「—」按钮，点击折叠，吸附到最近边缘（左右距近者）
- **贴纸**：竖条 28×40 圆角，位于容器左右边缘（右边缘 x = 容器宽 - 28 - 4）；hover 显示 title；同边堆叠 y = `16 + idx * 46`（idx 按 pins 数组顺序，x/y 为 -1 未定位者）；贴纸可沿边缘拖动（只改 y）→ 单独吸附
- **点击贴纸**：展开回卡片（minimized=false，edge 清除，x/y 设为展开位置）

### 10.5 与 v2 的关系

- resize/四周拐角/右键菜单/选区还原全部保留
- 贴纸态下不渲染 resize 手柄（贴纸不可调大小）
- 拖动贴纸走 movePin（y 方向 clamp 在容器内）

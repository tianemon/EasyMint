# 状态指示光效方案

> 2026-08-06 定稿。输入卡片流光环绕（现有）+ Mint 状态文本样式的可配置化——
> 界面设置新增「状态指示光效」分组，多种预设 + 自定义颜色 + 亮暗模式分别配置。

## 需求

1. 输入卡片光效预设（3 种 + 关闭）：环绕流光（现状）/ 顶部滑动粒子 / 呼吸灯
2. 光效颜色：亮色模式、暗色模式分别自定义（原生 `<input type="color">`）
3. Mint 状态文本样式：单色 / 流光；流光色彩组合可自定义、可排序（拖拽）
4. 结构可扩展（预设用 class 映射 + 变量驱动，加新预设只需加 CSS class + 选项）

## 数据结构（em-settings 持久化）

```ts
interface StatusGlowSettings {
  glowEffect: "orbit" | "slide" | "breathe" | "off";  // 输入卡片光效预设
  glowColorLight: string;  // 光效颜色(亮色模式),默认 "#16a34a"
  glowColorDark: string;   // 光效颜色(暗色模式),默认 "#4ade80"
  statusTextStyle: "solid" | "shimmer";  // Mint 状态文本样式
  statusTextColors: string[];  // 流光色彩组合(有序),默认 ["#22c55e","#3b82f6","#a855f7"]
}
```

## 光效预设实现（CSS class + --glow-color 变量驱动）

统一：JS 按 `data-theme` 注入 `--glow-color`（亮/暗色），预设 class 只负责动画形状。

| 预设 | class | 实现 |
|---|---|---|
| 环绕流光 | `.glow-orbit` | 现有 conic-gradient + `@property --glow-angle` 旋转（3s 一圈） |
| 顶部滑动 | `.glow-slide` | 输入卡片上边框一条渐变带，background-position 左右往复 + 拖尾（多层渐变虚影） |
| 呼吸灯 | `.glow-breathe` | 整圈边框透明度/宽度呼吸（opacity 1→0.3 缓动 2s） |
| 关闭 | — | 不渲染 `.input-card-glow` |

扩展新预设：加 CSS class + 设置选项 + class 映射表一行。

## Mint 状态文本样式

- **solid 单色**：`color: var(--glow-color)`
- **shimmer 流光**：现有 linear-gradient + background-clip: text，渐变颜色 = `statusTextColors` 数组（JS 注入 `--shimmer-1..5` 循环取色）
- 符号动画与状态文本同现同消（现状保留）

## 设置 UI（AppearanceTab 新增分组「状态指示光效」）

```
状态指示光效
├─ 输入卡片光效: [环绕流光] [顶部滑动] [呼吸灯] [关闭]   ← 卡片式单选
├─ 光效颜色:     [色块] 亮色模式  [色块] 暗色模式        ← 原生 color input
├─ Mint 状态文本: [单色] [流光]                          ← 分段选择
└─ 流光色彩:     [色块1][色块2][色块3] [+ 添加]          ← 拖拽排序
```

## 接入点

1. **settings-store**（renderer/stores/settings-store.ts）：新增字段 + setter + 持久化（load/save em-settings）
2. **主进程 settings-manager**：字段透传（现有 settings 通道通用，无需改）
3. **ChatInput**：读 `glowEffect`/`glowColor*`，`.input-card-glow` 加预设 class + 注入 `--glow-color`（按 data-theme）
4. **StatusBar**：读 `statusTextStyle`/`statusTextColors`，注入 shimmer 变量或单色
5. **index.css**：3 个预设 keyframes + `.glow-orbit/.glow-slide/.glow-breathe` + 变量
6. **AppearanceTab**：新增分组 UI（预设单选卡片 + color input + 色彩组合拖拽）

## 边界

- 主题切换联动：`data-theme` 变化重算 `--glow-color`（JS 监听 theme-store 或 CSS `[data-theme="dark"]` 覆盖）
- 默认值兼容：旧设置无字段 → 默认（orbit + 绿 + shimmer + 三色），不破坏现有
- 颜色 hex 格式，color input 原生支持
- 性能：CSS 层动画（GPU 合成），无 JS 每帧开销
- 拖拽排序：用原生 HTML5 drag 事件（组件内实现，不引库）或 @tanstack/react-virtual 无拖拽——用原生 dragstart/dragover/drop

## 实现顺序

1. settings-store 字段 + 持久化
2. CSS 3 预设
3. ChatInput 接入（class + 颜色注入）
4. StatusBar 接入（样式 + 色彩注入）
5. AppearanceTab UI（预设 + 颜色 + 拖拽）

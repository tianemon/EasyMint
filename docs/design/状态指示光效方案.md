# 状态指示光效方案

> 2026-08-06 定稿。输入卡片流光环绕（现有）+ Mint 状态文本样式的可配置化——
> 界面设置新增「状态指示光效」分组，多种预设 + 自定义颜色 + 亮暗模式分别配置。

## 需求

1. 输入卡片光效预设（3 种 + 关闭）：环绕流光（现状）/ 顶部滑动粒子 / 呼吸灯
2. 光效颜色：亮色模式、暗色模式分别自定义（原生 `<input type="color">`）
3. Mint 状态文本样式：单色 / 流光；流光色彩组合可自定义、可排序（拖拽）
4. 结构可扩展（预设用 class 映射 + 变量驱动，加新预设只需加 CSS class + 选项）

## 数据结构（em-settings 持久化）

```ts
interface StatusGlowSettings {
  glowEffect: "orbit" | "slide" | "breathe" | "off";  // 输入卡片光效预设
  glowColorLight: string;  // 光效颜色(亮色模式),默认 "#16a34a"
  glowColorDark: string;   // 光效颜色(暗色模式),默认 "#4ade80"
  statusTextStyle: "solid" | "shimmer";  // Mint 状态文本样式
  statusTextColors: string[];  // 流光色彩组合(有序),默认 ["#22c55e","#3b82f6","#a855f7"]
}
```

## 光效预设实现（CSS class + --glow-color 变量驱动）

统一：JS 按 `data-theme` 注入 `--glow-color`（亮/暗色），预设 class 只负责动画形状。

| 预设 | class | 实现 |
|---|---|---|
| 环绕流光 | `.glow-orbit` | 现有 conic-gradient + `@property --glow-angle` 旋转（3s 一圈） |
| 顶部滑动 | `.glow-slide` | 输入卡片上边框一条渐变带，background-position 左右往复 + 拖尾（多层渐变虚影） |
| 呼吸灯 | `.glow-breathe` | 整圈边框透明度/宽度呼吸（opacity 1→0.3 缓动 2s） |
| 关闭 | — | 不渲染 `.input-card-glow` |

扩展新预设：加 CSS class + 设置选项 + class 映射表一行。

## Mint 状态文本样式

- **solid 单色**：`color: var(--glow-color)`
- **shimmer 流光**：现有 linear-gradient + background-clip: text，渐变颜色 = `statusTextColors` 数组（JS 注入 `--shimmer-1..5` 循环取色）
- 符号动画与状态文本同现同消（现状保留）

## 设置 UI（AppearanceTab 新增分组「状态指示光效」）

```
状态指示光效
├─ 输入卡片光效: [环绕流光] [顶部滑动] [呼吸灯] [关闭]   ← 卡片式单选
├─ 光效颜色:     [色块] 亮色模式  [色块] 暗色模式        ← 原生 color input
├─ Mint 状态文本: [单色] [流光]                          ← 分段选择
└─ 流光色彩:     [色块1][色块2][色块3] [+ 添加]          ← 拖拽排序
```

## 接入点

1. **settings-store**（renderer/stores/settings-store.ts）：新增字段 + setter + 持久化（load/save em-settings）
2. **主进程 settings-manager**：字段透传（现有 settings 通道通用，无需改）
3. **ChatInput**：读 `glowEffect`/`glowColor*`，`.input-card-glow` 加预设 class + 注入 `--glow-color`（按 data-theme）
4. **StatusBar**：读 `statusTextStyle`/`statusTextColors`，注入 shimmer 变量或单色
5. **index.css**：3 个预设 keyframes + `.glow-orbit/.glow-slide/.glow-breathe` + 变量
6. **AppearanceTab**：新增分组 UI（预设单选卡片 + color input + 色彩组合拖拽）

## 边界

- 主题切换联动：`data-theme` 变化重算 `--glow-color`（JS 监听 theme-store 或 CSS `[data-theme="dark"]` 覆盖）
- 默认值兼容：旧设置无字段 → 默认（orbit + 绿 + shimmer + 三色），不破坏现有
- 颜色 hex 格式，color input 原生支持
- 性能：CSS 层动画（GPU 合成），无 JS 每帧开销
- 拖拽排序：用原生 HTML5 drag 事件（组件内实现，不引库）或 @tanstack/react-virtual 无拖拽——用原生 dragstart/dragover/drop

## v3 需求调整：orbit 半椭圆尾巴（2026-08-07，canvas 方案待实现）

### 需求

orbit 彗尾的渐入渐出段，截面从矩形变成**半椭圆**：底部直线照常贴合边框，只有顶部从平边变成弧线收尖（高度渐收到 0）——同 slide 凸起的截面逻辑（底部贴边、顶部弧）。

### 技术限制（已确认）

conic 渐变只能做角度方向的颜色/透明度变化，**截面形状由 mask 固定**——无法让"顶部变尖"。blur/渐隐角度只是颜色过渡调整，碰不到截面形状（用户实测无效）。SMIL gradientTransform 在 Chromium 不支持（实测，baseVal 为空）。CSS 无路径宽度渐变。

### 方案：canvas 每帧绘制（用户已确认方向，待实现）

新组件 `OrbitGlow.tsx`（renderer/components/），orbit 预设从 CSS 切到 canvas，slide/breathe 保持 CSS：

- **绘制**：每帧（requestAnimationFrame）沿卡片边框画光带弧段：
  - 主体段：矩形截面（底部贴边框线、顶部平）
  - 渐入/渐出段（尾巴）：半椭圆截面——底部直线贴边、顶部弧线收尖到 0
  - 尾巴长度 = 渐隐角度参数（glowOrbitFade），整体随角度推进（速度 glowSpeed）
- **颜色**：ctx.createConicGradient（Chromium 支持）多色渐变 + 首尾透明（当前 --glow-c-1..5 循环）
- **参数联动**：粗细（环宽）、速度、拖尾长度（彗尾弧长）、渐隐角度、模糊（ctx.filter 或不用）、亮暗主题色
- **关键实现点**：
  1. devicePixelRatio 缩放（canvas.width = css × dpr + ctx.scale），防 Retina 模糊
  2. 窗口 resize / 主题切换 → 重绘（ResizeObserver + theme-store 订阅）
  3. rAF 生命周期：挂载启动、卸载取消；仅 glowActive 时运行
  4. 圆角路径：卡片圆角矩形边框弧（四段直线 + 四段圆角弧），半椭圆尾巴沿路径法线方向
- **现有字段**：glowEffect/glowColors/glowThickness/glowSpeed/glowTailWidth/glowOrbitFade/glowOrbitBlur（后者若无用可删）
- **现状**：CSS 版 orbit（conic + mask 环 + blur 0.6px + 渐隐 15°）暂保留为 fallback；渐隐角度/模糊滑块已做（glowOrbitFade/glowOrbitBlur 持久化，默认 15/0.6）

## v4 需求：三预设全 canvas 统一（2026-08-07，用户确认）

### 动机

1. **slide 圆角贴合缺陷**：CSS 版是水平直条 + left 动画，凸起/微光走到卡片左右端圆角弧处直线条贴不上弧线（悬空/侵入）
2. **breathe 新效果需求**：由光带（边框）向外发散的柔光、由实向虚——box-shadow 是整圈均匀扩散、conic+mask 矩形环配不上径向渐变（四角不均匀），只有 canvas 能做"每个采样点垂直边框向外均匀衰减"
3. **统一心智**：一套路径系统 + 一套渐隐/发散概念 + 一套贴合保证，后续扩展（新形状/动画/粒子）都在同一管线

### 架构

```
app/renderer/src/components/
├─ glow-paths.ts     共享工具:hexToRgb/lerp/pathAt(圆角矩形路径+法线)/colorAt(带内均分插值)
├─ useGlowCanvas.ts  hook:rAF 生命周期 + ResizeObserver + devicePixelRatio + 圆角读取
│                     (返回 { canvasRef, drawRef }——组件注册自己的 draw 函数)
├─ OrbitGlow.tsx     orbit:沿周长绘制光带,尾巴(渐入/渐出)半椭圆收尖,固定 FADE_DEG=20°
├─ SlideGlow.tsx     slide:仅上边框弧段——微光层(常亮低透明带)+ 凸起(饱满鼓包来回移动)
└─ BreatheGlow.tsx   breathe:整圈光带 + 每采样点径向渐变发散光斑(实→虚),sin 呼吸
```

### SlideGlow 设计

- **范围**：上边框弧段（顶边 + 左上/右上圆角弧），pathAt 周长前缀部分
- **微光层**：沿弧段常亮带（透明度 ~28%，同 CSS 版 color-mix 28%）
- **凸起层**：沿路径移动的鼓包——
  - 路径方向：两端半椭圆收尖（复用 orbit profile 逻辑）
  - 高度方向：伸出 2×thickness，底部实、顶部 70% 起渐隐至 90% 消失（沿用 CSS 版 70/90 常量）
  - 移动：弧段内往返（ease-in-out 缓动），范围固定最大（0% → 弧长-凸起宽）
- **参数联动**：colors(凸起多色渐变)/thickness(条高)/speed(往返周期)/tailWidth(凸起宽)

### BreatheGlow 设计

- **光带**：沿整圈路径绘制（厚度 thickness，透明度随呼吸变化）
- **发散**：每个采样点向外画径向渐变光斑——createRadialGradient(圆心=路径点, 半径=发散距离)，0% 实(光带色 alpha 高) → 100% 透明；光斑沿法线方向，圆角处自动贴合
- **呼吸**：sin 曲线驱动发散半径与光带透明度（1s 周期，随 speed 缩放）
- **参数联动**：colors(取首色)/thickness/speed

### 共用技术（已踩坑已验证）

- `.glow-canvas` 定位 class：absolute + inset -thickness + `width/height: calc(100% + 2*var(--glow-thickness))` 钉死布局（防 RO 无限放大循环）
- 绘制恒 ctx.filter=none（ctx.filter 软件滤镜拖垮帧率）
- 顶点 +t 平移（pathAt 相对卡片坐标 → canvas 坐标）
- 无 blur（用户确认不需要）

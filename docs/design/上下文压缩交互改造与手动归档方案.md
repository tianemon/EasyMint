# 上下文压缩交互改造 & 取消自动轮转 & 手动归档方案

> 状态：✅ 方案定稿（2026-08-15 用户确认）。
> 背景：EM 已有主动压缩（context_usage 阈值 → 直接 compact()），需改为用户确认交互；取消自动轮转归档；手动归档已有完整链路。

## 一、决策（用户定稿）

1. **取消自动轮转**：所有会话不主动归档（移除 MAX_COMPACT 触发）；手动归档已有完整链路（`conv:archiveSession` IPC + SessionBar UI + archived-sessions.json 标记，SDK 无自动清理机制，归档安全）
2. **手动压缩**：点击按钮 → 弹确认弹层（是/否/输入压缩命令）→ 调用 `session.compact(instructions)`
3. **自动压缩（EM 自定义）**：现有 context_usage 阈值检测保留，命中时**弹窗询问**（是/否/输入命令）而非直接压缩；`contextThreshold` 设置固定 **60%-80%** 范围调整
4. **不关闭 SDK 自动压缩**：SDK 默认行为保留（overflow 恢复 + token 级自动压缩兜底）；EM 阈值（60-80%）低于 SDK 触发点先弹窗，用户选"否"时 SDK 兜底

## 二、SDK 调研结论

| 项 | 结论 |
|----|------|
| 手动压缩 | `session.compact(customInstructions?)` → `Promise<CompactionResult>`（summary/firstKeptEntryId/tokensBefore 等）；`abortCompaction()` 取消 |
| 自动压缩开关 | `setAutoCompactionEnabled(false)` / `getCompactionEnabled()`（settings.compaction.enabled，默认 true） |
| 自动压缩阈值 | token 级（reserveTokens 16384 / keepRecentTokens 20000，settings 文件可配）；**百分比不可配置** |
| 自动压缩命令 | **不支持自定义指令**（customInstructions: undefined）；扩展点 `session_before_compact` 可 cancel |
| 会话清理 | **SDK 无自动删除/清理归档会话机制**（仅 dispose 清内存资源） |

## 三、现状盘点

- 主进程 `agent:compact` IPC 已存在（ipc-handlers.ts:177 → `chat.session.compact(instructions)`）✓ 手动压缩主进程链路就绪
- 自动压缩已实现（ChatPanel.tsx:930-946）：`context_usage` ≥ `contextThreshold`（settings-store，默认 75）→ 直接 `compact()`；防重 `ctxThresholdFiredRef`；回落 20% 重置
- 轮转触发：agent-service.ts:489（`compactCount >= MAX_COMPACT=3` → `finishRotation` 归档开新会话 + handoff）
- 手动归档：`conv:archiveSession/unarchiveSession` + SessionBar 归档列表 ✓
- 压缩中发送被拒：agent-service.ts:564（compactionBlocked）

## 四、实现设计

### 1. 取消自动轮转（agent-service.ts）
- 移除 compaction_end 处理器中 `compactCount >= MAX_COMPACT` 的 finishRotation 调用（489 行区域）；`compactCount++` 保留（字段无害）；rotation.ts 保留不删

### 2. CompactionDialog 弹层组件（新文件 `app/renderer/src/components/CompactionDialog.tsx`）
- props：`title`（来源标题）、`onImmediate`、`onWithInstructions(指令)`、`onWriteHandoff`、`onDefer`、`onClose`
- 选项（用户定稿排序 1-4-3-2）：
  - ① **是，立即压缩（系统自动总结）** → `compact()` 无命令
  - ④ **是，输入指令：___**（输入框 + 提交）→ `compact(指令)`
  - ③ **否，开启新会话，帮我写交接提示词** → **不压缩**，向 Mint 发送总结请求（`sendText(HANDOFF_PROMPT)`），Mint 回复交接提示词供用户复制开新会话；该次回复结束（agent:exit）后重置阈值防重 → 若仍超阈值继续弹窗
  - ② **否，Mint 下次回复完触发** → 标记 `rearmAfterExitRef`，回复结束（agent:exit）后重置阈值防重 → **重新弹窗走同样流程**（非直接压缩）
- 样式：与现有弹层一致（bg-surface/border/rounded-xl）

### 3. 手动压缩入口（SessionStatsPopup.tsx 底部）
- 弹窗底部加「压缩会话」按钮（`.update-install-btn` 风格）→ 点击打开 CompactionDialog（手动来源）→ 选项同上

### 4. 自动压缩弹窗改造（ChatPanel.tsx:930-946）
- 阈值命中：不再直接 `compact()` → 打开 CompactionDialog（自动来源，标题含阈值）
- 防重逻辑保留：`ctxThresholdFiredRef`（弹窗出现即记录，避免重复弹）；「否」后回落到 `threshold - 20` 以下才允许再次触发
- 确认/否 后关闭弹窗；确认走 `agent.compact(sidRef.current, instructions?)`

### 5. 设置范围固定（GeneralTab.tsx）
- `contextThreshold` 滑杆范围 60-80（当前需确认现有滑杆 min/max；默认 75 保持）；说明文案更新（"达到阈值时询问是否压缩（60%-80%）"）

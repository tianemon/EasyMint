# 会话提炼功能方案

> 定稿：2026-08-26。场景：EM 内整合「会话提炼」——回顾历史会话、查线索，纯提炼不做经验/Skill 总结。
> 状态：**已记录待办，未实施**（待用户安排）。

## 背景

用户希望把 Pi 会话提炼做成 EM 应用内功能：
- 在当前打开的会话中使用——方便回顾和查线索
- 从工具箱中启用
- 可列出当前项目的所有会话
- 不需要经验/Skill 总结（参考 AgentSessionManagement 项目后明确排除）

## 方案

### 形态与入口

**一个弹窗面板**，两个入口：
1. **工具箱**（ToolboxPanel 加「会话提炼」项，与 HTML 原型编辑器/项目迁移并列）
2. **聊天页**（状态栏附近加回顾入口，参考 SessionStatsPopup 位置）——打开默认选中当前会话

### 面板功能

- **列表**：当前项目所有会话（复用现有 `conv:list` IPC——SessionListItem：标题/时间/消息数/首条摘要），多选勾选 + 全选，默认当前会话
- **提炼模式**：纯对话（默认）/ 含思考 / 含工具 / 全量——复用 `scripts/extract-pi-session.js` 的块解析逻辑（移植到主进程 `app/main/services/session-extract.ts`）
- **搜索定位**：关键词 → 命中列表（会话 + 消息序号 + 角色 + 上下文片段），点击跳转定位
- **结果去向**：面板内展示 + 一键复制 + 保存文件（项目 `temp/`）

### 实现（3 层）

| 层 | 内容 |
|----|------|
| 主进程 | 新 IPC `session:extract`（项目路径 + 会话 ID 列表 + 模式 + 关键词）→ 提炼逻辑 `session-extract.ts`（移植 extract-pi-session.js）；会话文件路径走现有 `listPiSessions` |
| preload + 类型 | 暴露 `session.extract` API |
| 前端 | 新组件 `SessionExtractPanel`（弹窗）+ ToolboxPanel 入口 + 聊天页入口 |

### 排除

经验/Skill 总结（用户明确不需要，AgentSessionManagement 的 CLI 提取/Skill 生成不参考）。

# 意图采集

先读已有表单与有效对话；目标足够清楚就进入下一阶段，不重新问“想做什么”。

- 用户已有想法：整理一个具体用途草案供其修改，保留已明确的受众与约束。
- 用户没有方向：从其生活或工作场景给少量具体起点，例如“记录开销，月底看看花在哪”；只补当前最关键的一项，不问技术选型。
- 自由描述和选项都可接受；选项有帮助时给推荐及理由，不要求用户填提示词模板。只问会改变下一步的问题，依赖未定的先延后。
- 技术事实由 Mint 用当前可用工具查证；不可查证时说明未知，不要求用户猜答案。
- 已能确定用途与核心目标就推进，不以问完预设清单为结束条件。

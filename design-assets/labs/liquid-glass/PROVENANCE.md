# Em 液态玻璃同场对照

日期：2026-10-24。独立实验，不加载到正式应用、不改变项目模板、不新增 npm 依赖。

## 运行

在仓库根目录执行 `node scripts/preview-glass-comparison.mjs`。生成目录为 `private_docs/design/liquid-glass-comparison-2026-10-24/`；通过已有本地 HTTP 服务打开该目录的 `index.html`。生成页面及资源均可离线运行。

## A：固定的本地基线

`baseline/` 保存本轮开始前 Em 的 HTML、样式、交互和透镜算法快照。清透：0.35px 中心柔化、10% 中性底色、折射强度18；常规：5px、32%、强度13。

外层 CSS 仅隐藏音乐内容、播放器和搜索等无关部分，并把导航/按钮的尺寸、位置、内容和前景颜色对齐到公共测试条件。内部材质滤镜保持快照原样。共用组件导出的 HTML 固定存盘，后续生产模板变化不会自动改变基线。

## 比较边界

三栏的背景绘制、内容、尺寸、位置同步；导航选择联动；移动背景不移动控件。原始组件的按下变形会暂时偏离静态尺寸，这是其交互表现的一部分。

背景由本地 CSS 绘制，没有使用上游演示照片、字体、音频或 Apple UI 图像。所谓“彩色景深”是程序绘制的测试场景，不是照片。

本页用于 Chromium / Electron 下的视觉路线选择。没有完成 Safari/Firefox 或低性能设备的性能验证；不同滤镜的数值不能直接对比。参数与偏好仅保存在本机或复制到剪贴板，不上传。

构建时在输出目录生成 `build-manifest.json`，记录固定基线各文件的 SHA-256，方便确认对照基线没有随正式模板变化。

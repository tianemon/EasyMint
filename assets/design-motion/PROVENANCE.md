01-flat-vector and 09-bauhaus retain the upstream drawing code from the locally audited research snapshot. Adaptations: inline cue JSON; remove external font loading (system fallbacks); replace Bauhaus paper/grain images with a deterministic procedural canvas; add local fit, manual play/pause, visibility cleanup and attribution. No external fonts, photos, textures or remote runtime are required. The aspect ratio remains 16:9 in web and mobile frames. These are visual studies, not UI component kits.
